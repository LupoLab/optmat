# The data

The curated records describe what each source reports. The review register explains
how those records and the models built from them were checked. The gallery shows
data, models, and validation figures generated from the committed records.

For a first introduction to these relationships, read
{doc}`/introduction/curation`. The {doc}`/quickstart` shows how to retrieve a
dataset and its source in Python; {mod}`optmat.datasets` is the reference interface.
