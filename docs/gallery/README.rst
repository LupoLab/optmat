Gallery
=======

Figures of the curated data, models and validation, generated from committed records
when their example scripts run during the documentation build. The scientific
chapters in the :doc:`/user-guide/index` explain the conventions, model choices and
uncertainties. Use the :doc:`/the-data/sources` catalogue to find each source record.

Comparison curves labelled ``luna_physdata`` are the formulas recorded in that
source, not a claim about current Luna.jl. The record identifies the ``modal-fixed``
branch and PR #425, including argon's commit ``56cc3ab``; it does not give a single
commit for every formula. Reference-state conventions are retained per formula.
See :doc:`/generated/sources/luna_physdata` and :doc:`/models` before interpreting
these comparisons.
