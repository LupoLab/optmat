# Archived enhancement proposals

This is where enhancement proposals go once they are final, rejected, withdrawn or
superseded. A final OEP is the record of how its functionality was proposed, built and
verified. It is not updated to follow later changes, which the manual describes
([OEP 0](../oep-0000-process.md) §6).
